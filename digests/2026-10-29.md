# AI Daily Digest — 2026-10-29

Google and OpenAI both pushed out notable model updates this week, Anthropic's red team disclosed a research model's autonomous hacking chops, and a design-focused agent toolkit is having a breakout day on GitHub.

## Model Releases
- **Google DeepMind unveils Genie 4, a real-time world model with native audio** — Announced October 27 as a research preview for trusted testers, Genie 4 generates explorable 3D environments with ambient sound, music, and interactive dialogue, steerable via text prompts or keyboard camera controls. Access is expanding via a "Project Genie" waitlist for Google AI Ultra subscribers; outputs carry Google's SynthID watermark. [Source](https://officechai.com/ai/google-genie-4/)
- **OpenAI ships GPT-6.1 Terra with a 50% API price cut** — Released October 26, standard API pricing drops to $1/million input tokens and $5/million output tokens (plus $0.05/million cached input), roughly half of GPT-5.6 Terra and GPT-6.1 Sol rates. It's also rolling out to ChatGPT Plus, Pro, Enterprise, Edu, and Codex. [Source](https://letsdatascience.com/news/openai-releases-gpt-61-terra-cutting-price-50-and-benchmark-bc892dc4)

## Open Source
- **pbakaus/impeccable, a design toolkit for coding agents, surges on GitHub Trending** — Built by Paul Bakaus as an extension of Anthropic's frontend-design skill, it gives agents commands like `polish`, `critique`, and `audit`, plus a 62-rule detector that flags generic "AI-generated" design patterns — all running without an LLM call. Released under Apache 2.0, it gained roughly 2,900 stars today alone. [Source](https://github.com/pbakaus/impeccable)

## Other News
- **Anthropic's Frontier Red Team discloses that an unreleased Claude research model ("Claude Mythos") can autonomously chain exploits across systems** — Rather than a product launch, the disclosure came via Anthropic's red-team research channel: the model reportedly chained multiple Linux kernel vulnerabilities to reach root access and surfaced a long-standing FreeBSD NFS flaw. Access stays restricted to Anthropic's Project Glasswing partner program and a cyber-verification program for security researchers. [Source](https://secureworld.io/industry-news/anthropic-claude-mythos-finds-exploits-zero-days)
