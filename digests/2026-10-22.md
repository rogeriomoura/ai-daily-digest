# AI Daily Digest — 2026-10-22

Another quiet day for verified news from most major labs, but Anthropic shipped a notable new product: a proactive, always-on agent aimed squarely at the "personal assistant" use case.

## Model Releases
- **Anthropic launches Claude Duet, a proactive background agent for Pro/Max subscribers** — Announced October 21 as a research preview (US-only, waitlisted), Duet runs on Claude Opus 5.5 inside its own virtual machine with a browser, so it keeps working even when the user's laptop or phone is off. It sends a morning brief based on connected apps, checks in every few hours, and messages the user when it judges something needs attention — handling tasks like scheduling, invoicing, or building dashboards and prototypes — while asking for sign-off before consequential actions. Internally the project was known as "Claude Loop." [Source](https://www.macrumors.com/2026/10/21/anthropic-claude-duet/)
