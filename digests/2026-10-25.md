# AI Daily Digest — 2026-10-25

Another quiet day for new model drops from the major labs, but open-source design tooling and a pair of Anthropic/Meta stories stood out.

## Open Source
- **Hallmark, a design skill that stops AI coding agents from looking "AI-generated," trends on GitHub** — Built by Together AI and released under MIT, Hallmark plugs into Claude Code, Codex, Cursor, and OpenCode, offering 48 visual themes plus a browser-based linter that flags common machine-made UI patterns (stacked eyebrow labels, empty placeholder frames) and a fresh-context reviewer as a final check; it gained over 1,300 stars in a single day. [Source](https://github.com/Nutlope/hallmark)
- **Anthropic donates its Agent Skills standard to the Agentic AI Foundation** — Announced October 22, Anthropic is handing governance of Agent Skills — the open specification for packaging reusable agent workflows it launched in October — to the vendor-neutral Agentic AI Foundation, which Anthropic co-founded with OpenAI and Block and which already stewards Model Context Protocol and AGENTS.md. [Source](https://www.anthropic.com/news)

## Other News
- **Meta's WhatsApp AI image tool sparks a Brazilian election dispute** — During Brazil's presidential runoff, users found Meta's AI image generator refused prompts naming candidate "Lula" while still producing campaign-style images for rival candidate "Flávio," prompting Lula's campaign to file a complaint with Brazil's top electoral court (TSE) alleging the tool favored the opposition. Meta called it an inconsistent filter gap affecting both campaigns' first names and numbers, said it was fixed the same day, and denied any intentional bias; Brazilian electoral rules bar AI systems from favoring candidates. [Source](https://www.dgabc.com.br/Noticia/4353310/meta-admite-falhas-na-campanha-de-lula-mas-nega-interferencia-nas-eleicoes)
- **Anthropic commits 5% of its equity to a new Public Benefit Fund** — Announced October 18 (pending shareholder approval), the fund is structured as a wholly owned Anthropic entity that would receive an initial 5% stake, with the board able to add up to 2% more for every 50% rise in company value above an undisclosed baseline. Combined with earlier founder pledges, Anthropic says roughly 20% of its equity is now earmarked for public-benefit purposes; the company has not yet decided how the fund's resources will be spent. [Source](https://www.aljazeera.com/economy/2026/10/19/anthropic-says-it-will-commit-5-of-shares-to-public-benefit-fund)
