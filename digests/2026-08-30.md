# AI Daily Digest — 2026-08-30

## Model Releases
- **Google ships Gemini 3.5 Transcribe** — A new speech-to-text model available in public preview via the Gemini API, split into a recorded-audio endpoint and a livestreams endpoint, posting a 2.6% average word error rate on pre-recorded audio (4.0% for real-time streaming) across 85+ languages. It's already powering Gboard's Rambler voice input and is coming to Chrome. [Source](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5-transcribe/)

## Open Source
- **"Ponytail" AI-coding skill goes viral, tops 100K GitHub stars** — A ruleset/plugin for coding agents (Claude Code, Codex, Copilot CLI, Cursor, and others) that pushes them to prefer the smallest possible solution — skip the feature, use the standard library, reach for an existing dependency — before writing custom code. It hit roughly 44,000 stars in its first 9 days and has kept climbing past 100K, with the author's benchmark suite claiming 54% fewer lines and 20% lower cost on real feature tickets at no loss of correctness. [Source](https://github.com/DietrichGebert/ponytail)

## Other News
- **OpenAI to cut off Cursor after SpaceX's $60B acquisition** — OpenAI told Cursor it will wind down their model-access contract by November 12, citing "our experience with Elon Musk's companies violating contracts" (pointing to Twitter/X and a Musk admission that xAI breached OpenAI's terms). Cursor's CEO says OpenAI models account for only about 5% of Cursor's traffic and that the two sides are still discussing the decision. [Source](https://www.cnbc.com/2026/08/29/openai-cursor-spacex-model-access.html)
- **Meta preps "Hatch," a consumer AI-agent platform** — Internal documents describe Hatch as a persistent-agent superapp that can carry out multi-step tasks — bookings, deliveries, comparisons, email/calendar summaries — across services like DoorDash, Etsy, Reddit, and Outlook, with a possible $200/month premium tier. It's expected to launch within weeks, running on a new Meta model codenamed "Watermelon" slated for October. [Source](https://finance.yahoo.com/technology/ai/articles/meta-hatch-agent-platform-watermelon-113350203.html)
- **Nvidia's AVO agent harness pushes Claude Opus 5 to a perfect ARC-AGI-3 score** — Nvidia's "Agentic Variation Operators" system wraps a model with persistent memory and supervisory error-recovery, lifting Claude Opus 5 from a ~30% baseline to 100% across all 183 public-set levels, using 12% fewer actions than the prior leader — without any retraining. The result is Nvidia's own reimplementation of the benchmark harness and covers only the public evaluation set. [Source](https://developer.nvidia.com/blog/nvidia-avo-reaches-100-on-arc-agi-3-demonstrating-a-frontier-level-general-purpose-architecture-for-long-horizon-autonomous-agents/)
