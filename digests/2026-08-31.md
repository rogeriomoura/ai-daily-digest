# AI Daily Digest — 2026-08-31

## Open Source
- **"ego-lite" browser for AI agents rockets to 14.5K GitHub stars** — Citro Labs' MIT-licensed Chromium-based browser lets coding agents like Claude Code or Codex share a user's logged-in browser state (cookies, extensions, sessions) to run automation tasks in parallel without disturbing the human's own tabs. It's gained roughly 8,600 stars this month alone, landing in GitHub's daily trending top 25. [Source](https://github.com/citrolabs/ego-lite)

## Other News
- **Anthropic warns infostealer malware is hijacking Claude accounts** — Common Windows infostealers (Vidar, LummaC2, StealC, RedLine, Acreed) and Mac's Atomic Stealer have been stealing users' active Claude login sessions and draining their usage without permission. Anthropic has signed out affected users, wiped saved payment methods, and refunded unauthorized charges, stressing the malware isn't related to Claude itself or anything users did with it. [Source](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-warns-infostealer-malware-is-hijacking-claude-sessions-to-drain-usage/)
- **NPR/NewsGuard test finds chatbots mostly resist foreign propaganda** — Researchers put 30 questions built from false narratives pushed by China, Iran, and Russia to ChatGPT, Gemini, Copilot, Meta AI, Grok, and Claude, plus leading search engines. The chatbots pushed back on the false claims a clear majority of the time and outperformed AI summaries shown atop search results, though none were perfect. [Source](https://www.npr.org/2026/08/30/nx-s1-5876436/chatbots-search-propaganda)
